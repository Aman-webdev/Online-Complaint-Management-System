# Online Complaint Management System

An MCA mini-project for submitting, viewing, and managing complaints.

## Technologies Used

- Java
- JSP and Servlets
- HTML and CSS
- MySQL
- Python
- Bubble Sort
- Apache Tomcat
- Eclipse IDE

## Features

- Submit a complaint
- View all submitted complaints
- Update complaint status
- View dashboard statistics
- Analyze and sort complaints by priority using Python and Bubble Sort

## Database Setup

Create a MySQL database named `complaint_db` and a table named `complaints`.

See the project source code for the table fields and SQL queries.

## How to Run

1. Install Java, Eclipse, Apache Tomcat, and MySQL.
2. Create the `complaint_db` database and `complaints` table.
3. Configure the MySQL JDBC driver and database connection.
4. Import the project into Eclipse.
5. Run the application on Tomcat.
6. Run `complaint_analysis.py` with Python to analyze complaints.
